# ספר המתכונים שלנו

אתר סטטי (PWA) עם מתכוני מאפים קפיאים לילדים: חיפוש, בחירת כמות, רשימת קניות מרוכזת וייצוא להדפסה.

- `index.html` — האפליקציה
- `recipes.json` — כל המתכונים (כאן מוסיפים ומעדכנים)
- `printables/` — דפי PDF להדפסה וקובץ עלויות

## אירוח
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## כללי המתכונים
בלי שמן קנולה (שומנים רק מאגוזים, חמאה ושמן זית). אגוזי מלך רק טחונים לאבקה. בלי שקדים.
