# ארכיטקטורה: סוכן מכירת יד שנייה

## מטרה
מתן שולח תמונות. הסוכן מוכר: עורך תמונות, כותב מודעה, מתמחר, מפרסם, עונה לקונים ומתמקח. כשקונה מוכן לקנות במחיר מקובל, הסוכן מעביר למתן לתיאום איסוף והעברת כסף.

## החלטות
| נושא | החלטה | נימוק |
|---|---|---|
| ממשק | בוט טלגרם | העלאת תמונות מהטלפון, אישור בכפתורים, התראות |
| פרסום | Playwright בפרופיל מחובר של מתן + אישור ידני לפני כל פרסום | אין API רשמי לפייסבוק מרקטפלייס וליד2 |
| תקשורת עם קונים | טקסט בלבד (מסנג'ר, הודעות יד2) | החלטת מתן |
| מיקוח | הסוכן מחליט לבד, מקסום מחיר, אין סגירה סופית | החלטת מתן |
| תמחור | הסוכן מחפש מחירים מקבילים ומציע, מתן מאשר | החלטת מתן |
| מודל | Claude עם ויזן (ברירת מחדל `claude-sonnet-5-5`, ניתן לשינוי ב-env) | |
| אחסון | SQLite | פשוט, מספיק לנפח |

## זרימה
```
תמונות (טלגרם) → זיהוי והפרדת פריטים → עריכת תמונות
  → תמחור (חיפוש מקביל) → כתיבת מודעה → [אישור מתן] → פרסום
  → פניות → מו"מ אוטומטי → [התראה למתן: קונה מוכן] → מתן סוגר
```

## סטטוסי פריט
`draft` → `awaiting_approval` → `published` → `negotiating` → `handoff` (קונה מוכן, מתן נכנס) → `sold`. בנוסף `archived`.

## מודולים (`src/secondhand_agent`)
- `bot.py` ממשק טלגרם: קבלת אלבומי תמונות, כפתורי אישור/עריכה
- `vision.py` זיהוי פריטים בתמונות והפרדה ביניהם (Claude vision, פלט JSON)
- `images.py` שיפור תמונות: כיוון, חיתוך, תאורה וניגודיות
- `pricing.py` המלצת מחיר ומחיר רצפה
- `listing.py` כותרת ותיאור
- `db.py` SQLite: פריטים, שיחות, הודעות
- `publishers/` (שלב 2) מתאמי Playwright ליד2 ולפייסבוק
- `negotiator.py` (שלב 3) מענה לקונים לפי `prompts/negotiator.md`

## עקרונות בטיחות
- סודות רק ב-`.env`, לא בקוד ולא ב-git.
- רק `OWNER_TELEGRAM_ID` מורשה לשלוט בבוט.
- פרסום רק אחרי אישור מפורש. קצב איטי והשהיות אנושיות, סשן מחובר קיים, למניעת חסימה.
- מחיר רצפה לא נחשף לקונים. הסוכן לא מבטיח מה שלא ידוע (מצב, אחריות) ולא ממציא פרטים.
- הסוכן לא סוגר עסקה ולא מקבל כסף. תמיד מעביר למתן.

## סיכונים
- חסימת חשבון בפייסבוק עקב אוטומציה: מקטינים סיכון, אבל הוא קיים. מומלץ לשקול פרסום ידני-מסייע (הסוכן ממלא טופס, מתן לוחץ "פרסם") כברירת מחדל.
- שינויי ממשק באתרים שוברים את הסלקטורים: מבודדים בתוך `publishers/`.
- תמונות מעובדות לא יציגו פריט אחר ממה שיש: עריכה שמרנית בלבד (בלי יצירת תוכן).
