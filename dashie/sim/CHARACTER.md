# מפרט הדמות של Dashie (ציור ב-M5GFX)

ארבעה עיצובים של אותה דמות, כולם בקוד `sim/index.html` (`faceBean`, `facePixel`, `faceLine`, `faceClassic`).
כולם נבנו **רק** מפרימיטיבים שיש ב-M5GFX, ולכן אפשר להעביר אותם ל-`face.h` בלי ספרייטים ובלי תמונות.

## כללים משותפים

**חתימה.** כמו `drawFace()` ב-`face.h`: `(cx, cy)` מרכז הפרצוף, `s` קנה מידה.
`s = 1.0` הוא הפרצוף הגדול ב-320x240, `s = 0.75` ב-240x135 (`L.faceS`), ובמסך הרעש `L.noiseFaceS` (0.42 / 0.3).
פרמטר נוסף `o = { mouth: 0..1, chef: bool, open: עיניים כפויות }`.

**מצבים.** `neutral, happy, worried, angry, confused, listen, think, talk, sleep`, ובנוסף `chef` (כובע שף, דגל ולא מצב).
`face.h` מכיר היום 8 (בלי `sleep`), לכן צריך להוסיף `SLEEP` ל-`enum class Mood` ופרמטר `bool chef`.

**פרימיטיבים בשימוש:**

| פרימיטיב | מה |
|---|---|
| `fillRect`, `fillRoundRect` | גוף, עיניים, פה פתוח |
| `fillCircle`, `drawCircle`, `fillEllipse` | עיניים, אנטנה, נקודות חשיבה, כובע |
| `fillTriangle` | עפעפיים (כועס, מודאג), טיפת זיעה |
| `drawLine` | דרך שלושת העוזרים למטה |

עוזרים (הכול `drawLine`, בדיוק כמו `faceMouth()` ב-`face.h`):

- `tline(x0,y0,x1,y1,th,c)`: קו עבה, `th` שורות `drawLine` מוזזות ב-Y.
- `arc(cx,cy,r,a0,a1,th,c)`: קשת כרצף קטעי `tline`, `max(6, |a1-a0|/12)` קטעים. זוויות במעלות, 0 = שעה 3, בכיוון השעון (מסך).
  אפשר להשתמש גם ב-`fillArc` של M5GFX, אבל כיוון הזוויות שלו צריך אימות על המכשיר, ולכן הדמות לא תלויה בו.
- `curveMouth(cx,cy,w,curve,th,c)`: פרבולה, זהה לקוד ב-`face.h`.

**צבעים.** `bg, fg, acc` מ-`THEMES` (`cyan / amber / green`). נגזרים:
`plate = mix(bg, fg, 0.10)`, `PINK = #ff7a90`, `SWEAT = #6fd0ff`, `RED = #ff503c`.
`mix(a,b,t)` הוא שילוב ליניארי ב-RGB, ובקושחה מחושב כקבוע לכל ערכת צבעים.

**אנימציה.**
- מצמוץ: `open = 0.08` למשך 130 ms, כל 2.5-6 שניות (כמו `face.h`). `listen` ו-`sleep` בלי מצמוץ.
- מבט: `gx = sin(now/2300)·A·s`, `gy = sin(now/3100)·B·s` (A, B לפי עיצוב), ב-`think` מבט למעלה-שמאלה.
- מעבר בין מצבים: מצמוץ של 130 ms ו-"קפיצה" של קנה המידה `s ·= 1 + 0.10·sin(π·t/260)` ל-260 ms (`devFace`).
- `talk`: גובה הפה לפי `mouthOpen` (0..1, כבר מחושב ב-`main.cpp` מעוצמת השמע).

**גבולות כדי שייכנס בשני הפרופילים.** כל העיצובים נכנסים בטווח האנכי `[cy-50s, cy+72s]`
(למעט האנטנה והכובע, ראו למטה) וברוחב ±100s. אצל `bean` הרוחב כולל אוזניים, כדי שיכנס
ב-`noiseFaceX = 30` במסך 240x135.

**כובע שף** (כשמשמרת פעילה): הפרצוף מתכווץ ל-`s·0.8`, ו-`cy` עולה ל-`max(cy, 2 + H·s')` כדי שהכובע לא ייחתך
מלמעלה (`H` = 96 ב-bean, 94 ב-classic, 68 ב-line; ל-pixel חישוב לפי בלוקים). ההכרעה "מתי כובע" היא `shift::active()`.

## א. שעועית-רובוט (`bean`, ברירת המחדל)

ראש עגול כמסך (visor) עם אוזניים ואנטנה. העיניים והפה בצבע `acc`, הרקע של הראש `plate`.

| רכיב | קואורדינטות (יחסית ל-cx, cy, s) | פרימיטיב |
|---|---|---|
| ראש (מסגרת) | x: ±88s, y: `hcy ± 57s` עם `hcy = cy + 15s`, רדיוס 52s, צבע `rim` | `fillRoundRect` |
| ראש (פנים) | נכנס 4s מכל צד, רדיוס 48s, צבע `plate` | `fillRoundRect` |
| אוזניים | מלבן 11s x 32s ב-x = ±(88s) (נכנס 3s לראש), רדיוס 5s | `fillRoundRect` |
| אנטנה | קו מ-`top` עד `top-7s` (עובי 3s), כדור ברדיוס 4s ב-`top-8s` | `tline`, `fillCircle` |
| עיניים | מרכז ב-`cx ± 48s`, `ey = hcy - 6s`, אליפסה 21s x 27s (x `open`) | `fillEllipse` |
| נצנוץ | עיגול ברדיוס 5s ב-(`x - 0.35·rx`, `y - 0.42·ry`) בצבע `fg`, רק כשהעין פתוחה | `fillCircle` |
| פה | מרכז `hcy + 30s` | `curveMouth` |

`rim` = `acc`, בכועס `mix(acc, RED, 0.65)`, בשינה `mix(acc, bg, 0.55)`.

מצבים (כל מה שמעבר לברירת המחדל):

| מצב | שינוי |
|---|---|
| neutral | פה: רוחב 16s, עקמומיות 4s |
| happy | עיניים כקשת "∩": `arc(x, eyy+8s, 17s, 205..335, עובי 5s)`; פה רוחב 22s, עקמומיות 12s; לחיים: אליפסה 9s x 4.5s ב-(±(48s+8s), `ey+26s`) בצבע `mix(plate, PINK, 0.7)` |
| worried | עפעף: משולש בצבע `plate` מעל כל עין, קודקוד חיצוני למטה (`(x-rx-3, eyy-ry-3), (x+rx+3, eyy-ry-3), (x-rx-3, eyy-0.05ry)`, בעין ימין מראה); פה הפוך (רוחב 16s, עקמומיות -8s); טיפת זיעה ב-(`cx+hw-16s`, `top+20s`) |
| angry | עפעף הפוך (קודקוד פנימי), מסגרת אדומה, פה הפוך (18s, -7s) |
| confused | עין ימין נמוכה ל-60% וגבוהה ב-6s; פה זיגזג (4 קטעים, אמפליטודה 6s·0.8); סימן שאלה בפינה: `arc` 190..370 ברדיוס 7s, קו, נקודה |
| listen | עיניים ×1.15, בלי מצמוץ, פה עיגול 6s, כדור האנטנה פועם (+3s) עם טבעת; "גלי קול": 2 קשתות (רדיוס 14s ו-22s, ±45°) משני צידי האוזניים |
| think | מבט (-9s, -9s), פה קו 16s, שלוש נקודות בפינה העליונה של הראש (רדיוס 2.5s, 3.5s, 4.5s), הפעילה בצבע `acc`, מתחלפות כל 300 ms; כדור האנטנה מהבהב |
| talk | פה: `fillRoundRect` ברוחב 36s, גובה `(4 + 26·mouth)s`, רדיוס חצי גובה |
| sleep | עיניים כקשת "∪" (`arc` 25..155, עובי 4s), פה קו 12s, שתי אותיות Z (7s ו-9s) בין העיניים, כדור האנטנה כבוי |
| chef | כובע: 3 עיגולים (רדיוס 20s, 24s, 20s) ב-(`cx-28s, top-20s`), (`cx, top-30s`), (`cx+28s, top-20s`), פס `fillRoundRect` 92s x 16s ב-`top-12s`, שני קווי קפל בצבע `mix(fg, bg, 0.3)`; האנטנה מוסתרת |

## ב. פיקסל רטרו (`pixel`)

רשת בלוקים 20 עמודות x 14 שורות (18 שורות עם כובע). גודל בלוק `u = max(3, floor(10.5·s))` (`8·s` עם כובע).
מקור הרשת: `x0 = round(cx - 10u)`, `y0 = round(cy + 10s - 7u)` (עם כובע `max(2, cy + 10s - 9u)`).
כל הציור הוא `fillRect(x0 + c·u, y0 + r·u, w·u, h·u)` ב-`px(c,r,w,h,צבע)`. גם הראש וגם הפה בלוקים.

- **ראש (מסגרת, `acc`)**: `[3,0,14,1] [1,1,18,1] [0,2,20,10] [1,12,18,1] [3,13,14,1]`
- **ראש (פנים, `plate`)**: `[4,1,12,1] [2,2,16,1] [1,3,18,8] [2,11,16,1] [4,12,12,1]`
- **עיניים**: 3 עמודות, עין שמאל בעמודה `5 + gx`, ימין `12 + gx`, שורה 4, גובה 4 (5 ב-listen). `gx` = מבט מכומת (`round(sin(now/2300))`). נצנוץ: בלוק `fg` בפינה השמאלית-עליונה. מצמוץ: שורה אחת.
- **פה**, לפי מצב: neutral `[8,9,4,1]`; happy `[7,9,1,1] [8,10,4,1] [12,9,1,1]` ולחיים `[4,8]`, `[15,8]`; worried / angry `[7,10] [8,9,4,1] [12,10]`; confused זיגזג `[7,9] [8,10] [9,9] [10,10] [11,9] [12,10]`; think שלוש נקודות ב-`[8|10|12, 9]`; talk `[7,9,6,h]` עם `h = 1 + round(2·mouth)`; sleep `[9,10,2,1]`.
- **גבות** (angry / worried), בלוקים ב-`acc` בשורות 2-4. **עיניים** ב-happy כקשת `[c,er+1] [c+1,er] [c+2,er+1]`, ב-sleep קו `[c,6,3,1]`.
- **listen**: שני פסי קול אנכיים בעמודות 2 ו-17, גובה פועם 2/4/6.
- **כובע**: שורות -4..-1: `[7,-4,6,1] [5,-3,10,1] [4,-2,12,1] [5,-1,10,1]` בצבע `fg`, קפלים `[9,-3,1,2] [12,-3,1,2]`.

## ג. קווית מינימליסטית (`line`)

בלי ראש. העיניים בצבע `fg`, הדגשות ב-`acc`. עובי `th = max(2, round(4s))`.

| רכיב | קואורדינטות |
|---|---|
| עיניים | `fillCircle` ברדיוס `11s` ב-(`cx ± 46s + gx`, `cy + 5s + gy`); מצמוץ: קו אופקי |
| neutral | פה `curveMouth(cx, cy+42s, 16s, 4s)` |
| happy | עיניים `arc` 205..335 ברדיוס 16s, פה `curveMouth(cx, cy+38s, 24s, 12s)` ב-`acc` |
| worried / angry | גבות `tline` ב-`acc` מעל העיניים (שיפוע הפוך בין השניים); worried: טיפת זיעה; פה הפוך |
| confused | עין ימין טבעת (`fillCircle` fg ואז `fillCircle` bg), גבה מורמת, זיגזג, סימן שאלה |
| listen | עיניים ×1.25, פה עיגול 6s, 2 זוגות קשתות "גלים" משני הצדדים |
| think | מבט (-8s, -8s), שלוש נקודות בפה (רדיוס 3s, 4s, 5s) |
| talk | פה: `fillEllipse` 22s x `(3 + 16·mouth)s` |
| sleep | עיניים `arc` 25..155, פה קו, שתי Z |
| chef | קווי מתאר: 3 קשתות (`arc`) וקווי הפס, ב-`fg`, מעל העיניים |

## ד. קלאסית (`classic`)

העתק של `drawFace()` ב-`face.h` (עיניים `fillRoundRect` 56s x 76s, פה `faceMouth`), בתוספת `sleep` (עיניים צרות ופה ישר) וכובע שף.

## עלויות ציור

הערכה לפריים: bean עד כ-90 קריאות (רובן קטעי קו של קשתות), pixel עד כ-45 `fillRect`, line עד כ-60, classic כ-20.
על Core2 זה זניח. ב-Plus2 כדאי להתחיל מ-pixel או classic אם יש בעיית ביצועים, והמדידה על המכשיר.
