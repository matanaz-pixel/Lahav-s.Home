# Dashie — עוזר אישי קטן לרכב על M5Stack

מכשיר על הדשבורד עם פרצוף מונפש, מד רעש בתא, מד G, יומן נסיעה, זיהוי תאונה ועוזר קולי.
כפתור או **קריאה כפולה בקול** מפעילים אותו.

## מה קונים
| חלק | הערה | מחיר משוער |
|---|---|---|
| M5Stack Core2 (v1.1) | מומלץ. מסך מגע, מיקרופון, רמקול, IMU | ~50$ |
| או M5Stack CoreS3 | חזק יותר, מתאים אם רוצים אחר כך מודל מילת הפעלה | ~60$ |
| מטען USB לרכב 5V/2A + כבל קצר | חיבור קבוע | ~10$ |
| מעמד/דבק 3M לדשבורד | | ~5$ |

## התקנה
1. התקינו PlatformIO (VS Code).
2. פתחו את `firmware/`, ערכו `src/config.h`: `WIFI_SSID`, `WIFI_PASS` (hotspot של הטלפון), `BRIDGE_URL`.
3. `pio run -e core2 -t upload` (או `-e cores3`).
4. אופציונלי: הרצת ה-bridge (`bridge/server.py`) לתמלול ותשובות חכמות.

## הפעלה
- לחיצה על **A** או נגיעה בפרצוף.
- אמירה חזקה פעמיים ברצף ("היי, היי") בתוך כשנייה וחצי.
- **B** מחליף מסך, **C** הגדרות.

## מגבלות (בכנות)
- זו לא מילת הפעלה אמיתית. הטריגר הכפול מבוסס אנרגיה ועלול לטעות ברעש חזק. להפעלה אמיתית על מילה שלכם אמנו מודל ב-Edge Impulse והפעילו `USE_EI_KWS`.
- הממשק במכשיר באנגלית. עברית דורשת פונט ו-RTL (שלב 2).
- הזמן והתשובות דורשים אינטרנט דרך הטלפון ו-bridge. בלי זה, הכול חוץ מהעוזר הקולי עובד offline.
- התראת התאונה מקומית בלבד, ואינה תחליף למערכת חירום.
- בטיחות: התקינו במקום שאינו מסתיר את הדרך, ואל תסתכלו על המסך בנסיעה. העוזר תוכנן להיות קולי.

## הדמיה
פתחו את `sim/index.html` בדפדפן. אפשר לדבר אליו עם המיקרופון של המחשב ולנסות הכול לפני שקונים חומרה.
