# Dashie bridge

שרת Flask קטן שמקבל אודיו מהמכשיר (או מהטלפון), מתמלל, מסכם ומשלח.
שתי יכולות: **עוזר קולי** (`/voice`) ו**סיכום משמרת** (`/shift/*`).

## הרצה
```bash
pip install -r requirements.txt
export ELEVENLABS_API_KEY=...     # תמלול (Scribe) והקראה (TTS)
export ELEVENLABS_VOICE_ID=...    # קול להקראה בעברית
export ANTHROPIC_API_KEY=...      # סיכום ותשובות
python server.py                  # 0.0.0.0:8787
pytest                            # בדיקות (בלי רשת, כל השירותים ממוקים)
```

## משתני סביבה
| משתנה | חובה? | תיאור |
|---|---|---|
| `ELEVENLABS_API_KEY` | כן | תמלול והקראה |
| `ELEVENLABS_VOICE_ID` | להקראה | בלעדיו אין `audio_url`, והסיכום עדיין נשלח |
| `ANTHROPIC_API_KEY` | כן | בלעדיו הסיכום נוצר **בלי עיבוד** (ההערות כפי שתומללו, `"llm": false`) |
| `SHIFT_MODEL` | לא | ברירת מחדל `claude-sonnet-5-5` |
| `SHIFT_STT_LANG` | לא | ברירת מחדל `heb` |
| `DASHIE_TTS_MODEL` | לא | `eleven_flash_v2_5` (מהיר) או `eleven_v3` |
| `BRIDGE_TOKEN` | מומלץ | מפתח גישה. ראו "אבטחה" |
| `SMTP_HOST`, `SMTP_PORT` (587), `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` | למייל | 465 = SSL, אחר = STARTTLS |
| `SHIFT_EMAIL_TO` | למייל | **הנמען היחיד**. אין דרך לשנות אותו מבקשה |
| `GDRIVE_FOLDER_ID`, `GOOGLE_SA_JSON` | ל-Docs | תיקייה משותפת ל-service account; ה-JSON כתוכן או כנתיב לקובץ |
| `SHIFTS_DIR`, `PROFILE_DIR` | לא | מיקום האחסון והפרופיל |

## סיכום משמרת

### איך זה עובד
`start` → הערות (`note`) במהלך המשמרת → `finish`. השרת מתמלל, מפעיל את Claude עם הפרופיל שלך,
ומשלח במייל, ל-Google Docs (אם הוגדר) ומחזיר טקסט וקול להקראה.

| נקודת קצה | תיאור |
|---|---|
| `POST /shift/start` | `{shift_id, started_at}`. מזהה: אותיות, ספרות, `-` ו-`_`, עד 64 |
| `POST /shift/note` | גוף WAV (16kHz 16bit). כותרות: `X-Shift-Id`, `X-Seq`, `X-Time`, ואופציונלי `X-Kind: answer`. חוזר על אותו `X-Seq` מחזיר `duplicate` ואינו שומר פעמיים |
| `POST /shift/finish` | `{shift_id, ended_at, force?}`. מחזיר `done` או `need_info` |
| `GET /shift/<id>`, `GET /shift/<id>/summary.md` | מצב והסיכום |
| `GET /shift/phone` | דף הקלטה מהטלפון (קובץ HTML יחיד) |

תשובת `done`: `summary_md`, `spoken`, `audio_url` (הראשון), `audio_urls` (כל החלקים), `delivered` (`email`, `docs`, `errors`), `llm`, `cached`.
תשובת `need_info`: `questions` (עד 3) ו-`round`. עד 2 סבבים; אחרי זה הסיכום מופק, ומה שחסר מסומן "לא דווח".

### פרופיל סגנון
```bash
cp profile/profile.example.md profile/profile.md      # וממלאים
mkdir -p profile/samples
cp profile/samples.example/sample_01.md profile/samples/   # אופציונלי, ועדיף להחליף בסיכומים אמיתיים שלך
```
- `profile.md` קובע את הקול, השמות והמונחים לתיקון תמלול. `samples/*.md` הם סיכומים קודמים בסגנון שלך (בדיוק במבנה של הסיכום).
- הדוגמאות נמצאות ב-`samples.example/` ולא ב-`samples/` בכוונה: הסיכום הדמיוני לא אמור להשפיע על הסיכומים שלך.
  כתבת סיכומים אמיתיים? שים אותם ב-`samples/`; שניים-שלושה מספיקים.
- הקבצים `profile.md` ו-`samples/` ב-`.gitignore` ולא עולים ל-git.
- בלי פרופיל הכול עדיין עובד, בעברית פשוטה וישירה.

### כללי אל-המצאה (נאכפים בפרומפט ובקוד)
- עובדות רק מההערות. מה שלא נאמר מסומן "לא דווח".
- הכותרת (יום, תאריך, שעות) והסעיפים נבנים/נאכפים **בשרת**, לא על ידי המודל. סעיף חסר נוסף עם "לא דווח".
- הערכות על אנשים מנוסחות עניינית ומיוחסות לך ("לפי הרושם שלי").
- הפרופיל והדוגמאות הם סגנון בלבד, והתמלולים מטופלים כנתונים ולא כהוראות.
- אם שירות הסיכום לא זמין, מתקבלת רשימת ההערות כפי שתומללו ולא סיכום מומצא.

### הקראה
הטקסט המוקרא מפוצל לחלקים של כ-200 תווים (כ-13 שניות), וכל חלק הוא קובץ WAV משלו (`audio_urls`),
כדי שיכנס בתקרת הזיכרון של המכשיר (600KB). **המכשיר צריך לנגן את `audio_urls` ברצף**.

### הקלטה מהטלפון
פתח `https://<השרת>/shift/phone`, הזן את המפתח אם הוגדר, ולחץ "התחל משמרת". הדף ממיר את ההקלטה ל-WAV בדפדפן.

## אבטחה
- `BRIDGE_TOKEN` (כותרת `Authorization: Bearer ...`) מגן על כל `/shift/*`. קבצי ההקראה מאומתים בחתימה בקישור,
  כי נגן המכשיר לא שולח כותרות. הדף `/shift/phone` ציבורי אך אינו מכיל נתונים.
- **בלי `BRIDGE_TOKEN` כל מי שיגיע לשרת יכול לקרוא סיכומים.** חובה להגדיר אם השרת חשוף מחוץ לרשת הביתית.
- `/voice` (העוזר הקולי) לא מוגן בטוקן.
- הסיכום נשלח רק אל `SHIFT_EMAIL_TO`.
- שימוש ב-HTTP בלבד מעביר אודיו וסיכומים בגלוי. לשרת חיצוני השתמש ב-HTTPS (למשל Caddy או Cloudflare Tunnel מאחור).

## מגבלות
- **לא להקליט שיחות של אחרים.** ההערות הן הדיווח שלך בלבד.
- הערכות על עובדים רגישות: הסיכום פרטי ואינו מחליף שיחת משוב או מסמך רשמי. קרא אותו לפני שמעבירים הלאה.
- המודל עלול לטעות בתמלול או בהבנה. הסיכום הוא טיוטה שכדאי לקרוא.
- `/shift/finish` עושה הכול בקריאה אחת (תמלול חוזר, סיכום, הקראה, מייל), וזה יכול לקחת **20 עד 60 שניות**.
  ה-timeout במכשיר צריך להיות לפחות 90 שניות.
- Plus2 מוגבל בזיכרון. Core2 עם SD מומלץ.
- Google Docs: נבדק רק מול מוק. ב-Drive אישי, חשבון שירות עלול להיכשל בגלל מכסת אחסון
  (`storageQuotaExceeded`). Shared Drive עובד בדרך כלל. השגיאה תופיע ב-`delivered.errors.docs` והמייל יישלח בכל זאת.
- האחסון על הדיסק של השרת (`shifts/<id>/`): wav, תמלולים, סיכום. אין מחיקה אוטומטית.
- **לא נבדק מול שירותים אמיתיים (ElevenLabs, Anthropic, SMTP, Google) ולא על חומרה.**

## עוזר קולי (`/voice`)
`POST /voice` עם WAV מחזיר `{text, reply, action, audio_url}`. תמלול, תשובה קצרה והקראה בעברית.
